# DESCRIPTION OF TASK

The objective of this project is to build and visualize a Decision Tree Classification model using the Scikit-Learn library. The Iris dataset was used to train and evaluate the model for predicting flower species based on features such as sepal length, sepal width, petal length, and petal width.

The dataset was divided into training and testing sets using the train_test_split() function. A DecisionTreeClassifier was trained on the training data and used to make predictions on the test data. The model performance was evaluated using Accuracy Score and Classification Report.

Finally, the trained Decision Tree was visualized using Matplotlib and Scikit-Learn's plot_tree() function, providing a graphical representation of the decision-making process.
